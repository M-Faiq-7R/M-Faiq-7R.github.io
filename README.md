# Personal Portfolio

A clean, responsive portfolio website showcasing my projects, skills, and learning journey as a Computer Science student at FAST University.

**Live Demo:** [*(Portfolio)*](https://m-faiq-7r.github.io/)

---

## About

This portfolio serves as my personal website where I share:

- My background
- Technical skills
- Featured projects
- Contact information

The goal was to create a fast, minimal, and professional portfolio without unnecessary animations or visual clutter.

---

## Features

- Responsive design
- Modern dark theme
- Sticky navigation
- Smooth scrolling
- Active navigation highlighting
- Back-to-top button
- Featured project section
- Mobile-friendly layout
- Clean and semantic HTML

## Featured Project

### MedVault

A learning-focused hospital management application created with AI assistance to study authentication, session management, and secure backend development.

The project helped me understand how real-world backend systems authenticate users, manage sessions, and protect sensitive information.
